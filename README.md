# LandMonitor Dagestan

**Сайт:** [https://ulaymi.github.io/land-monitor-dagestan/](https://ulaymi.github.io/land-monitor-dagestan/)

Интерактивный веб-прототип мониторинга деградации земель в Республике
Дагестан. Проект адаптирует архитектуру `Desertification` под географию и
муниципальное устройство Дагестана.

## Что работает

- интерактивная карта административного контура Дагестана;
- поиск реальных сцен Copernicus Sentinel-2 L2A;
- бесплатный спутниковый режим в естественных цветах Sentinel-2 RGB;
- периодическая мозаика, закрывающая всю территорию лучшими сценами каждого
  тайла Sentinel-2;
- два ползунка для независимой настройки начала и конца окна спутниковой
  мозаики;
- переключение слоёв NDVI, BSI, NDMI и модельного комплексного риска;
- фильтрация по периоду и допустимой облачности;
- выбор одной из 51 муниципальной территории;
- временная шкала сцен, зональная статистика и экспорт краткого отчёта;
- переход к выбранной территории в Google Earth Web;
- экспорт контура республики или района в KML для Google Earth Web/Pro;
- адаптивный интерфейс для компьютера, планшета и телефона;
- статическая сборка и автоматическая публикация в GitHub Pages.

Без ключа API приложение ищет сцены `sentinel-2-l2a` в STAC-каталоге
Microsoft Planetary Computer. Data API рассчитывает зональную статистику NDVI,
NDMI и BSI внутри выбранной административной геометрии. Комплексный риск —
взвешенная эвристика прототипа, а не официальное экологическое заключение.
Спутниковый режим формируется из видимых каналов B04, B03 и B02 без Google
Cloud, платёжного аккаунта и пользовательского API-ключа.
Для каждого MGRS-тайла система выбирает оптимальную сцену из заданного периода,
а карта рассчитывает фактический процент покрытия выбранной территории.

## Запуск

Нужен Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

Приложение откроется на [http://localhost:3000](http://localhost:3000).

## Проверка и сборка

```bash
npm test
npm run build:pages
```

Статическая сборка GitHub Pages создаётся в каталоге `out`.

## Google Earth

Кнопка `Google Earth` открывает текущую территорию в веб-версии сервиса без
API-ключа. Кнопка `Скачать KML` создаёт на устройстве пользователя файл с
точной геометрией выбранного района, системой координат WGS 84 и описанием
активного спутникового среза. Файл можно импортировать в Google Earth Web или
Google Earth Pro.

## Данные и методика

- спутниковые сцены: Copernicus Sentinel-2 L2A через Microsoft Planetary
  Computer;
- контур субъекта: предоставленный `Dagestan.geojson`, технически проверенный и
  сопоставленный с официальной площадью региона;
- муниципальные территории: geoBoundaries gbOpen RUS ADM2 на основе
  OpenStreetMap/Wambacher, ODbL 1.0;
- базовая карта и гидрография: OpenStreetMap, ODbL 1.0;
- NDVI: `(B08 - B04) / (B08 + B04)`;
- NDMI: `(B08 - B11) / (B08 + B11)`;
- BSI: `((B11 + B04) - (B08 + B02)) / ((B11 + B04) + (B08 + B02))`.

Подробный результат проверки границы: [docs/boundary-audit.md](docs/boundary-audit.md).

## Важное ограничение границы

Предоставленный файл корректен для аналитической визуализации, но его
метаданные указывают на экспорт CartoDB 2013 года, а не на юридически значимую
выгрузку ЕГРН. Для кадастровых, землеустроительных или иных правовых задач
контур необходимо заменить сведениями ЕГРН/НСПД Росреестра.
